# Add-on Products

**Category:** concept · **Baseline:** Frends 6.2

## Purpose
Beyond the core platform, Frends offers supporting products documented separately.

## Products
- **Business Automation Portal (BAP)** — a business-facing automation portal. Docs:
  `https://docs.frends.com/bap/`.
- **API Portal** — a developer/consumer portal for published APIs. Docs:
  `https://docs.frends.com/api-portal/`.

Fetch their docs when a task touches them; they version independently of the core platform.
