# Text Annotation shape

**Category:** shape (artifact / documentation) · **Baseline:** Frends 6.2

## Purpose
A **documentation-only** shape that adds a free-text note to the canvas, attached to an element. No
runtime effect.

## Serialization
BPMN `textAnnotation` (+ `association`). Like [Group](group.md), it is visual and does **not** get an
`ElementParameters` entry. See [../process-file-format/bpmn-xml.md](../process-file-format/bpmn-xml.md).
