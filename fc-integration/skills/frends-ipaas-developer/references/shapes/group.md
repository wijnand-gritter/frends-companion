# Group shape

**Category:** shape (artifact / documentation) · **Baseline:** Frends 6.2

## Purpose
A **documentation-only** shape that visually ties related shapes together on the canvas. No runtime
effect and no result.

## Serialization
BPMN `group` (with an `association`). It is a visual annotation and does **not** get its own
`ElementParameters` entry (confirmed: absent from the palette export's ElementParameters). See
[../process-file-format/bpmn-xml.md](../process-file-format/bpmn-xml.md).
