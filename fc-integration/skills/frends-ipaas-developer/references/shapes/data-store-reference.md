# Data Store Reference shape

**Category:** shape (artifact / documentation) · **Baseline:** Frends 6.2

## Purpose
A **documentation-only** shape that makes a data store (a persistent place data is read from or
written to) visible on the canvas. No runtime effect.

## Fields / configuration
None that affect execution.

## Serialization
BPMN `dataStoreReference`; JSON `Type` **23**; empty `Parameters` (`{}`), `SelectedTypeId` None.
Confirmed against a 6.2 export. See
[../process-file-format/shape-type-codes.md](../process-file-format/shape-type-codes.md).
