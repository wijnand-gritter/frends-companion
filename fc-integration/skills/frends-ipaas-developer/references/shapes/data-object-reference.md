# Data Object Reference shape

**Category:** shape (artifact / documentation) · **Baseline:** Frends 6.2

## Purpose
A **documentation-only** shape that makes a data flow visible on the canvas (a piece of data the
Process reads or produces). It has no runtime effect.

## Fields / configuration
None that affect execution.

## Serialization
BPMN `dataObjectReference`; JSON `Type` **22**; empty `Parameters` (`{}`), `SelectedTypeId` None.
Confirmed against a 6.2 export. (In 5.7 templates this code differed — see the drift note in
[../process-file-format/shape-type-codes.md](../process-file-format/shape-type-codes.md).)
